All tracks are licensed CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/),
so commercial use needs no attribution. Credits are kept anyway. Files are the 128 kbps MP3 previews served by
Freesound, found through the Openverse API (license filter: cc0). Each file name is the soundtrack id used by the API.
